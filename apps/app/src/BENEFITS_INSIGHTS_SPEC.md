# Benefits Income Insights

## Meaningful Insights That Provide Real Value

---

## Design Philosophy (Applied to Benefits Income)

| ✅ Valuable Insight                                 | ❌ Not Valuable                    |
| --------------------------------------------------- | ---------------------------------- |
| Warns before you lose benefits by earning too much  | Just showing benefit amount        |
| Shows actual tax impact (Social Security is tricky) | Assuming all benefits are tax-free |
| Counts down temporary benefits, prompts planning    | Static "you receive X"             |
| Tracks annual adjustments (COLA)                    | Ignoring inflation adjustments     |

---

## Benefits Income Subtypes Context

| Subtype                   | Key Characteristics                        | Primary Concerns                                |
| ------------------------- | ------------------------------------------ | ----------------------------------------------- |
| **Social Security**       | Long-term, COLA adjusted, complex taxation | Earnings limits (if early), taxation thresholds |
| **Pension**               | Fixed or COLA adjusted, taxable            | Stability, survivor benefits                    |
| **Disability**            | Income limits, work restrictions           | Earning too much, losing benefits               |
| **Unemployment**          | Temporary, taxable                         | Duration limits, transition planning            |
| **Veterans Benefits**     | Various types, some tax-free               | Eligibility changes                             |
| **Child Support/Alimony** | Fixed term or until event                  | End date awareness, tax treatment               |

## Insight #1: The Income Cliff Warning

### Why It's Valuable

Many benefits have **earnings limits** — if you earn too much from other sources, your benefits get reduced or eliminated entirely. This creates dangerous "income cliffs" where earning an extra $1 could cost you thousands in lost benefits. **This is the #1 financial trap for benefits recipients.**

### Calculation Logic

```typescript
function calculateIncomeCliffWarning(
  benefit: BenefitIncome,
  otherIncome: Income[]
): IncomeCliffAnalysis {
  // Get relevant earnings limits based on benefit type
  const limits = getBenefitEarningsLimits(benefit.benefitType, benefit.subType);

  if (!limits) {
    return { hasEarningsLimit: false };
  }

  // Calculate earned income (exclude investment income for most benefits)
  const earnedIncome = otherIncome
    .filter((i) => ['salary_wages', 'freelance_gig'].includes(i.incomeType))
    .reduce((sum, i) => sum + i.monthlyAmount * 12, 0);

  const monthlyEarnedIncome = earnedIncome / 12;
  const annualLimit = limits.annualLimit;
  const monthlyLimit = limits.monthlyLimit || annualLimit / 12;

  const buffer = annualLimit - earnedIncome;
  const monthlyBuffer = monthlyLimit - monthlyEarnedIncome;
  const percentOfLimit = (earnedIncome / annualLimit) * 100;

  // Determine status
  let status: 'safe' | 'caution' | 'danger' | 'over';
  if (earnedIncome > annualLimit) {
    status = 'over';
  } else if (percentOfLimit > 90) {
    status = 'danger';
  } else if (percentOfLimit > 75) {
    status = 'caution';
  } else {
    status = 'safe';
  }

  // Calculate impact if over
  let impactIfOver = null;
  if (limits.reductionType === 'gradual') {
    // Social Security style: $1 withheld per $2 over
    const amountOver = Math.max(0, earnedIncome - annualLimit);
    impactIfOver = {
      type: 'reduction',
      formula: '$1 withheld for every $2 over limit',
      currentReduction: amountOver / 2,
    };
  } else if (limits.reductionType === 'cliff') {
    // Disability style: lose entire benefit
    impactIfOver = {
      type: 'cliff',
      formula: 'Entire benefit at risk',
      potentialLoss: benefit.monthlyAmount * 12,
    };
  }

  return {
    hasEarningsLimit: true,
    benefitType: benefit.benefitType,
    monthlyBenefit: benefit.monthlyAmount,
    annualLimit,
    monthlyLimit,
    currentEarnedIncome: earnedIncome,
    buffer,
    monthlyBuffer,
    percentOfLimit,
    status,
    impactIfOver,
    safeToEarnMonthly: Math.max(0, monthlyBuffer),
    limitDisappearsAt: limits.expirationCondition, // e.g., "Full Retirement Age (67)"
  };
}
```

### When to Show

- Dashboard (if any earnings limit applies)
- Alert when approaching 75% of limit
- Urgent alert when within 90% of limit
- When user adds/increases other earned income

Many people assume benefits are tax-free — but **Social Security can be up to 85% taxable** depending on your total income. Pensions are usually fully taxable. Unemployment is taxable. This insight shows the **real after-tax amount** you receive.

### Calculation Logic

```typescript
function calculateBenefitsTaxReality(
  benefits: BenefitIncome[],
  otherIncome: Income[],
  userTaxProfile: TaxProfile
): BenefitsTaxAnalysis {
  const { marginalRate } = userTaxProfile;

  // Calculate other income for SS combined income calculation
  const otherAnnualIncome = otherIncome.reduce(
    (sum, i) => sum + i.monthlyAmount * 12,
    0
  );

  const benefitAnalysis = benefits.map((benefit) => {
    let taxablePercentage = 0;
    let explanation = '';

    switch (benefit.benefitSubtype) {
      case 'social_security':
        // Calculate combined income
        const ssAnnual = benefit.monthlyAmount * 12;
        const combinedIncome = otherAnnualIncome + ssAnnual * 0.5;

        // Determine taxable percentage (single filer thresholds)
        if (combinedIncome < 25000) {
          taxablePercentage = 0;
          explanation = 'Below threshold - tax-free';
        } else if (combinedIncome < 34000) {
          taxablePercentage = 0.5;
          explanation = '50% taxable based on combined income';
        } else {
          taxablePercentage = 0.85;
          explanation = '85% taxable based on combined income';
        }
        break;

      case 'pension':
        taxablePercentage = 1.0; // Usually fully taxable
        explanation = 'Fully taxable as ordinary income';
        break;

      case 'disability_ssdi':
        // Same rules as Social Security
        const ssdiAnnual = benefit.monthlyAmount * 12;
        const combinedIncomeSSI = otherAnnualIncome + ssdiAnnual * 0.5;

        if (combinedIncomeSSI < 25000) {
          taxablePercentage = 0;
        } else if (combinedIncomeSSI < 34000) {
          taxablePercentage = 0.5;
        } else {
          taxablePercentage = 0.85;
        }
        explanation = 'Taxed like Social Security';
        break;

      case 'disability_va':
      case 'veterans':
        taxablePercentage = 0;
        explanation = 'Tax-free';
        break;

      case 'unemployment':
        taxablePercentage = 1.0;
        explanation = 'Fully taxable as ordinary income';
        break;

      case 'child_support':
        taxablePercentage = 0;
        explanation = 'Tax-free to recipient';
        break;

      case 'alimony':
        // Depends on divorce date
        taxablePercentage =
          benefit.divorceDate < new Date('2019-01-01') ? 1.0 : 0;
        explanation =
          benefit.divorceDate < new Date('2019-01-01')
            ? 'Taxable (pre-2019 divorce)'
            : 'Tax-free (post-2018 divorce)';
        break;

      default:
        taxablePercentage = 0;
    }

    const monthlyTaxable = benefit.monthlyAmount * taxablePercentage;
    const monthlyTax = monthlyTaxable * marginalRate;
    const afterTax = benefit.monthlyAmount - monthlyTax;

    return {
      benefit,
      taxablePercentage,
      monthlyTaxable,
      monthlyTax,
      afterTax,
      explanation,
    };
  });

  const totalGross = benefits.reduce((sum, b) => sum + b.monthlyAmount, 0);
  const totalTax = benefitAnalysis.reduce((sum, b) => sum + b.monthlyTax, 0);
  const totalAfterTax = totalGross - totalTax;
  const keepPercentage = (totalAfterTax / totalGross) * 100;

  return {
    byBenefit: benefitAnalysis,
    totalGross,
    totalTax,
    totalAfterTax,
    keepPercentage,
    combinedIncome:
      otherAnnualIncome +
      benefits
        .filter((b) => b.benefitSubtype === 'social_security')
        .reduce((sum, b) => sum + b.monthlyAmount * 6, 0), // Half of SS
  };
}
```

```typescript
function calculateBenefitDuration(
  benefit: BenefitIncome
): BenefitDurationAnalysis {
  if (!benefit.endDate && !benefit.durationWeeks) {
    return { isTemporary: false };
  }

  const today = new Date();
  let endDate: Date;
  let totalDuration: number;
  let elapsed: number;
  let remaining: number;

  if (benefit.benefitSubtype === 'unemployment') {
    const startDate = benefit.startDate || today;
    const maxWeeks = benefit.durationWeeks || 26;
    endDate = addWeeks(startDate, maxWeeks);

    totalDuration = maxWeeks;
    elapsed = differenceInWeeks(today, startDate);
    remaining = maxWeeks - elapsed;
  } else if (benefit.benefitSubtype === 'child_support') {
    // Typically ends at age 18 or 19
    const childBirthDate = benefit.childBirthDate;
    const endAge = benefit.endAge || 18;
    endDate = addYears(childBirthDate, endAge);

    totalDuration = differenceInMonths(
      endDate,
      benefit.startDate || childBirthDate
    );
    elapsed = differenceInMonths(today, benefit.startDate || childBirthDate);
    remaining = differenceInMonths(endDate, today);
  } else if (benefit.endDate) {
    endDate = benefit.endDate;
    totalDuration = differenceInMonths(endDate, benefit.startDate || today);
    elapsed = differenceInMonths(today, benefit.startDate || today);
    remaining = differenceInMonths(endDate, today);
  }

  const remainingValue = benefit.monthlyAmount * remaining;
  const percentComplete = (elapsed / totalDuration) * 100;

  // Determine urgency
  let urgency: 'low' | 'medium' | 'high' | 'critical';
  if (remaining <= 4) {
    urgency = 'critical';
  } else if (remaining <= 12) {
    urgency = 'high';
  } else if (remaining <= 24) {
    urgency = 'medium';
  } else {
    urgency = 'low';
  }

  return {
    isTemporary: true,
    endDate,
    totalDuration,
    elapsed,
    remaining,
    remainingValue,
    percentComplete,
    urgency,
    monthlyAmount: benefit.monthlyAmount,
    incomeDropAmount: benefit.monthlyAmount,
  };
}
```

```typescript
function trackCOLAAdjustments(
  benefit: BenefitIncome,
  colaHistory: COLARecord[]
): COLAAnalysis {
  // Only applicable for certain benefit types
  if (
    !['social_security', 'disability_ssdi', 'pension'].includes(
      benefit.benefitSubtype
    )
  ) {
    return { hasCOLA: false };
  }

  // Calculate history
  const history = colaHistory.map((record, index) => {
    const previousAmount =
      index > 0
        ? colaHistory[index - 1].benefitAmount
        : record.benefitAmount / (1 + record.colaPercentage / 100);

    return {
      year: record.year,
      colaPercentage: record.colaPercentage,
      benefitAmount: record.benefitAmount,
      monthlyChange: record.benefitAmount - previousAmount,
      annualChange: (record.benefitAmount - previousAmount) * 12,
    };
  });

  // Calculate cumulative changes
  const oldestAmount =
    history[history.length - 1]?.benefitAmount || benefit.monthlyAmount;
  const newestAmount = benefit.monthlyAmount;
  const totalIncrease = newestAmount - oldestAmount;
  const totalIncreasePercent = (totalIncrease / oldestAmount) * 100;

  // Compare to inflation
  const cumulativeInflation = calculateCumulativeInflation(
    history.length // years
  );
  const beatsInflation = totalIncreasePercent >= cumulativeInflation;

  // Consider Medicare premium impact (for SS recipients)
  let netRealIncrease = totalIncrease;
  if (benefit.benefitSubtype === 'social_security' && benefit.hasMedicare) {
    const medicarePremiumIncrease = getMedicarePremiumIncrease(history.length);
    netRealIncrease = totalIncrease - medicarePremiumIncrease;
  }

  // Project next year
  const estimatedNextCOLA = getEstimatedCOLA(); // Based on current CPI
  const projectedNextBenefit =
    benefit.monthlyAmount * (1 + estimatedNextCOLA / 100);

  return {
    hasCOLA: true,
    currentBenefit: benefit.monthlyAmount,
    currentYearCOLA: history[0]?.colaPercentage,
    currentYearIncrease: history[0]?.monthlyChange,
    history,
    totalIncreaseAmount: totalIncrease,
    totalIncreasePercent,
    cumulativeInflation,
    beatsInflation,
    netRealIncrease,
    projectedNextYear: {
      estimatedCOLA: estimatedNextCOLA,
      projectedBenefit: projectedNextBenefit,
      announcementDate: 'October 2025',
    },
  };
}
```
