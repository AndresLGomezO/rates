# Log Payment Feature — Complete Design

## Design Philosophy

Logging payments should be **fast, flexible, and forgiving**. Users log payments in different contexts:

| Context                          | User Need                       | Design Response    |
| -------------------------------- | ------------------------------- | ------------------ |
| Just paid something              | Quick capture before forgetting | One-tap quick log  |
| Catching up on multiple payments | Efficient batch entry           | Multi-payment mode |
| Has a receipt/confirmation       | Don't want to type              | Scan & extract     |
| Hands are busy                   | Voice-first                     | Speak to log       |
| Reviewing an account             | Log while looking at details    | Contextual log     |
| Unsure what they paid            | Need help remembering           | Smart suggestions  |
